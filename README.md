# Amir Rafiq Bhat — Personal Academic & Engineering Portfolio

A modern, responsive, high-performance portfolio website tailored for **Amir Rafiq Bhat** (PhD Researcher in Computer Engineering, AI Research Scientist, and Senior Software Engineer).

---

## 🚀 Quick Preview (Offline / Local)
Simply double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Brave, Safari). No build tools, Node.js, or local servers required!

---

## 🌐 1-Click Free Hosting Options

### Option 1: GitHub Pages (Recommended — Your own `iamirrafiq.github.io` URL)
1. Create a new public repository on GitHub named: **`iamirrafiq.github.io`**
2. Upload the contents of this folder (`index.html`, etc.) into the repository.
3. Your portfolio will immediately be live worldwide at:  
   👉 **`https://iamirrafiq.github.io`**

### Option 2: Vercel (Instant Drag-and-Drop)
1. Go to [vercel.com](https://vercel.com) and log in with your GitHub account.
2. Drag and drop this `portfolio` folder directly onto the Vercel dashboard.
3. Your website will be live in 10 seconds with a free `.vercel.app` domain and automatic HTTPS SSL certificate.

### Option 3: Netlify (Drag-and-Drop)
1. Go to [netlify.com](https://netlify.com).
2. Drag and drop this `portfolio` folder into the Netlify Drop area.
3. Your site is live immediately!

## ✨ Features Included

- **Hero Section**: Bio, research focus, social links, CV download link, and an interactive Python code card (`researcher_profile.py`).
- **Featured Publication Spotlight**: Details of your Springer manuscript under review, complete with tags and a **1-click BibTeX copy** button.
- **Interactive Project Filtering**: Instant category filtering between:
  - *All Projects*
  - *LLMs & NLP* (Mental health Llama 3.1 thesis, Turkey earthquake NLP, Lecture conspectus)
  - *Health & Bio-AI* (ECG Arrhythmia classification, elderly care routing)
  - *Data & Cloud Systems* (Enterprise AWS ETL, reverse-engineered ERPs)
- **Dual-Track Experience Timeline**: Side-by-side view of **Academic Research / Teaching** vs. **Industry Software Engineering**.
- **Interactive Technical Skills Matrix**: Categorized tags for AI/LLMs, Programming Languages, Cloud/DevOps, and Spoken Languages.
- **Interactive Contact & Copy Email**: One-click email copy with animated toast notification.
- **Theme Switcher**: Dark mode and Light mode toggle with automatic state persistence in `localStorage`.
- **Zero Heavy Dependencies**: Pure semantic HTML5 + responsive Tailwind CSS with zero bloat.
